engine: Mix of AIE Bootstrap, console C++, WinForms (.NET), and OpenGL experiments
features:
  - Shop Game (2019) - text-based console market simulator with dynamic item pricing, my first exercise in classes, structs, and reusable C++
  - Simon (2019) - memory game built on an update/draw loop with class-driven state flow and a custom DynamicArray template
  - SlimeCube (2022) - OpenGL viewer that loaded complex meshes and simulated PBR materials, with ImGui controls and CMake cross-platform builds
---

These projects are where the fundamentals came from. AIE Melbourne gave me the groundwork - engine architecture, maths, and how a game is actually structured - and I taught myself an enormous amount on top of it by building these in my own time. SlimeCube was the turning point: putting a mesh and PBR pipeline together in OpenGL showed me how much deeper rendering goes, and it grew directly into the Vulkan SlimeProject. The jump from console games to a real-time graphics engine is the throughline of everything I have built since.
