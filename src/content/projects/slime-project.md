SlimeProject is a full game development stack - a custom Vulkan 1.3 engine (SlimeOdyssey) used to build a 2D platformer (SlimeGame). The engine focuses on clean, understandable Vulkan implementation while covering modern features like ECS, PBR, and cross-platform support. I wrote the engine, and Connor Young built SlimeGame on it with my guidance.
